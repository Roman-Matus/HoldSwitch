# Проверка на Windows

Ручной чек-лист перед выпуском версии.

Раскладки: русская и английская. Проверять в Блокноте, браузере, Word,
Telegram, «Командной строке», Windows Terminal.

| # | Действие | Ожидается |
|---|----------|-----------|
| 1 | Режим А. Обычный набор текста, быстро, с перекрытием клавиш | Текст без пропусков и перестановок |
| 2 | Shift + буква, отпустить Shift раньше буквы | Заглавная |
| 3 | Удержать `f` дольше 0,4 с | Язык сменился, `f` не напечаталась, плашка `RU` |
| 4 | Удержать ещё раз | Обратно на `EN` |
| 5 | Режим Б. Удержать `f` в EN | Язык RU, напечатано `а` |
| 6 | Режим В. Удержать `f` в EN | `f` появилась и стёрлась, язык RU |
| 7 | Удерживать букву 3 секунды | Одно переключение, никаких `ffff` |
| 8 | Удерживать Backspace / стрелку | Автоповтор работает |
| 9 | Ctrl+Z удерживать | Отмена повторяется, язык не меняется |
| 10 | Alt+Shift, Ctrl+Shift | Работают как раньше |
| 11 | Командная строка и Windows Terminal: удержание | Одно переключение (не два и не ноль) |
| 12 | Приложения из Магазина (Калькулятор, Параметры): удержание | Язык меняется |
| 13 | Плашка при двух мониторах | На мониторе с активным окном, фокус не отнимает |
| 13а | «Маленький, над курсором ввода»: Блокнот, Word, Chrome, Telegram | Плашка над мигающим курсором; где не нашёлся — над полем ввода, затем над указателем мыши. Способ по каждому переключению — в `%APPDATA%\HoldSwitch\caret.log` |
| 14 | Блокировка Win+L и вход обратно | Всё работает дальше |
| 15 | «Запускать вместе с Windows», перезагрузка | Значок на месте |

Пункты 11 и 12 — места, где Windows хуже всего переключает раскладку
программно; если там что-то не так, сообщите, в каком приложении.

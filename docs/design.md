# HoldSwitch — переключение раскладки долгим нажатием

Дата: 2026-09-24. Статус: тестовая версия (для владельца), потом — раздача.

## Что делает

Фоновая программа для Windows 10–11 x64 (на 7/8.1 — при установленном
Universal C Runtime). Долгое нажатие клавиши, печатающей
букву, цифру или символ, переключает раскладку на следующую в списке
Windows по кругу (RU → EN → RU …). Автоповтор таких клавиш убран.
После переключения в правом нижнем углу на секунду появляется плашка
с кодом нового языка и гаснет.

Ctrl+Shift / Alt+Shift продолжают работать как раньше.

## Какие клавиши участвуют

«Печатающие»: A–Z, 0–9 верхнего ряда, OEM-символы (`; = , - . / ` [ \ ] '`
и клавиша 102-й раскладки), цифры и знаки цифрового блока. Пробел — по
настройке, по умолчанию выключен (его удержание используют игры и
редакторы).

Клавиша обрабатывается, только если при её нажатии не зажаты Ctrl, Alt
или Win. Иначе это сочетание (Ctrl+C, Ctrl+Z с автоповтором и т. п.),
и оно проходит нетронутым. AltGr = Ctrl+Alt, поэтому символы AltGr тоже
проходят как есть.

Остальные клавиши (Enter, Backspace, стрелки, Tab, F1–F12,
модификаторы) программа не трогает, их автоповтор сохраняется.

События, которые уже кем-то вставлены программно (флаг `LLKHF_INJECTED`,
в том числе наши), всегда проходят без обработки.

## Три режима долгого нажатия (выбираются в меню трея)

- **А — только переключить** (по умолчанию). Нажатие придерживается. Если
  клавишу отпустили раньше порога — печатается как обычно. Если держат
  дольше порога — раскладка переключается, символ не печатается.
- **Б — переключить и напечатать.** Как А, но после переключения
  клавиша печатается уже в новой раскладке (`f` → `а`).
- **В — сразу напечатать, при удержании стереть.** Символ печатается при
  нажатии. Если держат дольше порога — вставляется Backspace и раскладка
  переключается.

Во всех режимах: за одно удержание — одно переключение; автоповторы
удерживаемой клавиши подавляются.

## Быстрый набор (перекрытие клавиш) в режимах А и Б

Пока клавиша придержана («ожидает»), любое другое событие клавиатуры
означает, что это было обычное нажатие:

1. ожидающая клавиша сразу печатается (вставляются её down + up);
2. если новое событие — нажатие другой печатающей клавиши, оно становится
   новым ожидающим;
3. иначе новое событие подавляется и вставляется заново после
   напечатанной клавиши — так сохраняется порядок. Пример: Shift↓ A↓
   Shift↑ A↑ даёт «A», а не «a».

Настоящее отпускание клавиши, которую мы уже напечатали за пользователя,
подавляется и ничего не сбрасывает.

В режиме В любое другое событие просто отменяет отсчёт удержания.

## Порог

Настраивается в меню: 300 / 400 / 500 / 600 / 800 мс. По умолчанию 400.

## Переключение раскладки

1. Берётся окно переднего плана, его поток и текущая раскладка
   (`GetKeyboardLayout`), список раскладок (`GetKeyboardLayoutList`),
   следующая по кругу.
2. Окну посылается `WM_INPUTLANGCHANGEREQUEST` с этой раскладкой.
3. Каждые 20 мс проверяется, что раскладка потока сменилась (до 300 мс).
4. Если не сменилась — запасной путь: вставляется системное сочетание
   переключения из реестра (`HKCU\Keyboard Layout\Toggle\Hotkey`:
   1 → Alt+Shift, 2 → Ctrl+Shift, иначе Win+Space) и снова ждём до 300 мс.
5. Итог — фактическая раскладка: её код показывает индикатор; в режиме Б
   после этого печатается удержанная клавиша.

## Индикатор

Окно без фокуса и прозрачное для мыши (`WS_EX_NOACTIVATE |
WS_EX_TRANSPARENT | WS_EX_LAYERED | WS_EX_TOPMOST | WS_EX_TOOLWINDOW`),
тёмная плашка со скруглёнными углами и кодом языка (`RU`, `EN`) из
`LOCALE_SISO639LANGNAME`. Правый нижний угол рабочей области монитора, на
котором окно переднего плана. Видна 900 мс, гаснет за 250 мс.

Цвет — фирменный синий с белой рамкой (тёмно-серая сливалась с фоном).

Вариант показа выбирается в меню «Индикатор языка»:

- в правом нижнем углу (64×40 при 100 %) — по умолчанию;
- маленький над курсором ввода (34×22). Курсор ищется по порядку:
  `GetGUIThreadInfo` (системный курсор классических окон; точка меньше 6 px
  и окна Qt считаются ненадёжными — Telegram обновляет её только при
  получении фокуса, — для них сначала UI Automation); UI Automation —
  `TextPattern2.GetCaretRange`, затем `TextPattern.GetSelection` (Windows 11,
  Word, Chrome, Edge; пустой диапазон курсора берётся по соседнему символу);
  MSAA `OBJID_CARET`; рамка сфокусированного поля высотой до 200 px; указатель
  мыши. Каждый поиск пишется в `%APPDATA%\HoldSwitch\caret.log` (способ, exe,
  класс окна, прямоугольник; без текста; до 256 КБ).
  Процесс работает в режиме Per-Monitor DPI v2, плашка масштабируется по
  монитору, на котором появляется.
  Сверху нет места — под курсором. Поиск идёт в отдельном потоке: чужое
  приложение может отвечать долго, а наш поток держит хук клавиатуры;
- не показывать.

## Трей и настройки

Значок рисуется программой. Меню (правый и левый щелчок):
Включено · Режим (А/Б/В) · Порог · Пробел тоже · Показывать индикатор ·
Запускать вместе с Windows · Выход.

Настройки — `%APPDATA%\HoldSwitch\settings.ini`. Автозапуск —
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run\HoldSwitch`.
Второй экземпляр не запускается (именованный мьютекс).

## Устройство кода

- `src/engine.{h,c}` — вся логика удержания, без Windows API: на входе
  событие клавиши или «тик таймера», на выходе — пропустить/подавить и
  список действий (вставить клавишу, запустить/остановить таймер,
  переключить раскладку [+ напечатать после]). Тестируется на Linux.
- `src/switcher.{h,c}` — переключение раскладки с проверкой и запасным
  путём.
- `src/indicator.{h,c}` — плашка.
- `src/settings.{h,c}` — ini и автозапуск.
- `src/main.c` — хук `WH_KEYBOARD_LL`, цикл сообщений, таймеры, трей.
- `tests/test_engine.c` — тесты движка (gcc).
- `build.sh` — тесты + сборка `.exe` через `zig cc`.

Модификаторы отслеживаются самим движком по событиям. При смене сеанса
(блокировка/разблокировка, `WM_WTSSESSION_CHANGE`) состояние движка
сбрасывается: пока открыт защищённый рабочий стол, хук не видит
отпусканий.

## Известные ограничения

- Не работает в окнах, запущенных от администратора, если сама программа
  запущена без прав (UIPI).
- Полноэкранные игры, удалённый рабочий стол — не поддерживаются;
  на время игры программу выключают в меню.
- В режимах А и Б буква появляется при отпускании клавиши (или при
  нажатии следующей), а не при нажатии.
- У `.exe` нет цифровой подписи — SmartScreen предупредит при первом
  запуске.

Вставка клавиш (`SendInput`) в режимах А/Б делается прямо из обработчика
хука, пока текущее событие подавляется: вставленные события встают в
очередь после него, так сохраняется порядок. Это проверяется на Windows
(пункты 1–2 чек-листа).

# HoldSwitch

**Смена языка в Windows долгим нажатием клавиши.**
Удерживайте любую клавишу с буквой, цифрой или символом чуть дольше обычного,
около полусекунды, — раскладка переключится на следующую (RU → EN → RU…).
Автоповтор этих клавиш убран.

[English version](README.md) · Версия 0.9.0 · © 2026 .NoxCode · [Лицензия MIT](LICENSE)

## Скачать

Скачайте `HoldSwitch-0.9.0-win-x64.zip` в разделе [Releases](../../releases),
распакуйте и запустите `HoldSwitch.exe`. Устанавливать ничего не нужно.
Windows 10/11, x64.

У файла пока нет цифровой подписи, поэтому Windows может показать «Система
Windows защитила ваш компьютер»: нажмите **Подробнее → Выполнить в любом случае**.

## Возможности

- **Три режима долгого нажатия**
  - **А** — только переключить язык (по умолчанию);
  - **Б** — переключить и напечатать символ уже в новом языке (`f` → `а`);
  - **В** — напечатать сразу, при удержании стереть и переключить.
- **Нет автоповтора** у букв, цифр и символов. Backspace, стрелки и сочетания
  с Ctrl/Alt/Win работают как обычно.
- **Индикатор языка** — маленькая плашка (`RU`, `EN`…) в углу экрана или прямо
  над курсором ввода.
- Настраиваемая длительность нажатия (300–800 мс), пробел по желанию,
  автозапуск вместе с Windows.
- Интерфейс на русском и английском.
- Alt+Shift и Ctrl+Shift работают как раньше.

Настройки — в меню значка **Яz** в трее.

## Приватность

HoldSwitch видит каждое нажатие клавиши — иначе он не может работать, — поэтому
вот точно, что он с ними делает:

- **Ничего не записывается и никуда не отправляется.** В программе нет сетевого
  кода вообще (она не подключает ни одной сетевой библиотеки) и набранный текст
  нигде не сохраняется.
- Настройки хранятся в `%APPDATA%\HoldSwitch\settings.ini`.
- Если плашка настроена «над курсором ввода», для диагностики ведётся
  `%APPDATA%\HoldSwitch\caret.log`: каким способом найден курсор, имя программы,
  класс окна и координаты. Никакого текста. Размер ограничен 256 КБ.
- Чтобы найти курсор ввода, программа пользуется специальными возможностями
  Windows (UI Automation, MSAA) — теми же, что экранные дикторы.

Исходный код небольшой — его можно прочитать или собрать программу самому (см. ниже).

## Ограничения

- Не работает в окнах, запущенных от администратора (диспетчер задач, терминал
  администратора), пока сам HoldSwitch запущен без прав администратора.
- В полноэкранных играх и при удалённом рабочем столе программу лучше выключить.
- В режимах А и Б символ появляется при отпускании клавиши (или при нажатии
  следующей): программе нужно сначала отличить короткое нажатие от долгого.
- Символы, набираемые с AltGr, и сочетания с Ctrl/Alt/Win не перехватываются.

## Сборка

`.exe` собирается на Linux компилятором C из [Zig](https://ziglang.org/),
тесты — системным `gcc`.

```bash
python3 -m venv .venv && .venv/bin/pip install ziglang   # один раз
./build.sh      # тесты и dist/HoldSwitch.exe
./package.sh    # zip для релиза в release/
```

## Устройство

- `src/engine.c` — логика долгого нажатия без Windows API, покрыта
  `tests/test_engine.c` (небольшой симулятор автоповтора, таймера и раскладок).
- `src/main.c` — низкоуровневый хук клавиатуры (`WH_KEYBOARD_LL`), трей, меню.
- `src/switcher.c` — смена раскладки через `WM_INPUTLANGCHANGEREQUEST` с проверкой
  и запасным путём через системное сочетание.
- `src/caret.c` — поиск курсора ввода: системный курсор, UI Automation
  (`TextPattern2`, `TextPattern`), MSAA, рамка поля ввода, указатель мыши.
- `src/indicator.c` — плашка с языком; `src/i18n.c` — строки интерфейса
  (покрыта `tests/test_i18n.c`); `src/settings.c` — настройки и автозапуск.

Устройство подробно: [docs/design.md](docs/design.md).
Ручной чек-лист проверки: [docs/testing.md](docs/testing.md).
